# 📚 FocusStudy

**FocusStudy** is a smart study planner designed especially for college students. It helps students create study plans, stay focused, and reduce distractions during study sessions.

## 🎯 Main Purpose

The main goal of FocusStudy is to provide students with a **Distraction-Free Focus Mode** where they can concentrate on their studies without unnecessary interruptions.

## ✨ Features

* 📅 Smart Study Planner
* ⏱️ Focus Study Sessions
* 🚫 Distraction-Free Focus Mode
* 📵 Call Blocking During Focus Sessions
* 🔕 Notification Blocking
* 🔔 Study Session Notifications
* 📊 Study Progress Tracking
* 📝 Task & Subject Management
* 🎯 Daily Study Goals
* 🌙 Simple and Modern UI
* 📱 Mobile-Friendly Design
* 🔐 User Authentication
* ☁️ Backend Database Support

## 🧠 Focus Mode

When a student starts a focus session:

1. Select a subject.
2. Set the study duration.
3. Start Focus Mode.
4. Reduce unnecessary notifications.
5. Block or silence incoming calls where supported.
6. Track the completed study session.
7. View progress after the session.

> **Note:** Call and notification blocking depends on the mobile operating system and the permissions available to the application.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/FocusStudy.git
```

### 2. Open the Project

Open the project in:

* IntelliJ IDEA
* Eclipse
* VS Code

### 3. Install Dependencies

Make sure **Java** and **Maven** are installed.

```bash
mvn clean install
```

### 4. Run the Application

```bash
mvn spring-boot:run
```

The application will start on:

```text
http://localhost:8080
```
